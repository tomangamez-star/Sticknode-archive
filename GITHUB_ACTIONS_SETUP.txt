GITHUB ACTIONS — PYTHON INGEST

The archive scraping job now runs directly on GitHub Actions. Render remains the Telegram bot/search host.

Required GitHub repository secrets:
- TELEGRAM_TOKEN
- DATABASE_URL
- ARCHIVE_CHAT_ID

No RENDER_INGEST_URL or RENDER_INGEST_SECRET is required for the archive-ingest workflow.

Python dependencies are already declared in requirements.txt, including curl_cffi. GitHub installs them automatically with:
  pip install -r requirements.txt

Run: Actions -> Stick Nodes archive ingest -> Run workflow.
Start with backfill_pages=1 for the first test.

Important: curl_cffi is used here as the HTTP client for ordinary requests. This project does not configure challenge circumvention or browser-fingerprint impersonation.
